Zorvok

Zorvok public pod registry

The free public registry for Zorvok, the CocoaPods-compatible dependency manager for iOS. It's served in CocoaPods' own CDN format, so this address works as a pod source for both zorvok install and plain pod install.

Install a pod from here

pod 'MyPod', :source => 'https://raw.githubusercontent.com/zorvok-dev/zorvok-specs/main/'

Publish yours

One command, like pod trunk push. A pod already on CocoaPods trunk can only be published here by its owners there, checked automatically.

brew install zorvok-dev/tap/zorvok
gh auth login        # once
zorvok trunk push    # in your pod's folder
